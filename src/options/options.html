Configure alert defaults and manage local tracking data.

Defaults

Newly tracked items use this threshold. Enter 1–99, or leave it blank for no default.

Target prices are set per product so values remain correct across Amazon currencies and regions.

Data Management

Tracked items and price history stay on this device. Chrome sync is used only for lightweight preferences. No account is required.

Longer retention uses more local storage space. Expired history is permanently removed.

Exports contain product names, Amazon URLs, prices, and history. Clearing history removes charts for every item; price tracking continues.
