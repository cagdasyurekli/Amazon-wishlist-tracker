# Support

For installation, usage, and troubleshooting, read the
[user manual](docs/USER_MANUAL.md) first.

If the problem remains, open a GitHub issue with the extension version or commit,
Chrome and operating-system versions, reproducible steps, and sanitized diagnostics.
Do not post Amazon cookies, account details, addresses, private wishlist IDs, exported
backups, or other shopping-interest data.

Security vulnerabilities must be reported privately through
[GitHub Private Vulnerability Reporting](https://github.com/cagdasyurekli/Amazon-wishlist-tracker/security/advisories/new),
not through a public issue.
