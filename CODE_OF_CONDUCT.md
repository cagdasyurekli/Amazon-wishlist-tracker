# Code of Conduct

## Our commitment

We are committed to a welcoming, respectful, and harassment-free project for everyone,
regardless of background, identity, experience level, or personal characteristics.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and evidence without attacking people.
- Respect privacy. Never publish credentials, personal information, private wishlists,
  shopping history, or other sensitive data.
- Accept maintainers' decisions about project scope, safety, and moderation.

Harassment, discrimination, threats, sexualized attention, deliberate intimidation,
doxxing, and repeated disruptive behavior are not acceptable.

## Scope and enforcement

This code applies in repository discussions, issues, pull requests, and other spaces
where someone represents this project. Maintainers may edit or remove content and may
temporarily or permanently restrict participation when behavior violates this code.

For an ordinary conduct concern, open a repository issue without including private
information. For threats, doxxing, or platform abuse, use GitHub's confidential
**Report abuse** mechanism. Security vulnerabilities belong in the repository's private
vulnerability-reporting channel.
