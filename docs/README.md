# Documentation

Start with the document that matches what you are trying to do:

## For users

- [User manual](USER_MANUAL.md): installation, product tracking, wishlist import and
  sync, alerts, backup and restore, migration, and troubleshooting.
- [Support](../SUPPORT.md): where to ask for help and what information is safe to
  include.
- [Privacy](../PRIVACY.md): storage areas, network access, data lifecycle, and
  deletion guidance.

## For contributors

- [Contributing](../CONTRIBUTING.md): repository boundaries, local checks, and pull
  request expectations.
- [Feature specifications](feature_specs.md): expected externally observable
  behavior.
- [Lessons learned](lessons_learned.md): durable implementation pitfalls and
  decisions.
- [Security policy](../SECURITY.md): security invariants, scope, and private
  vulnerability reporting.

## For maintainers

- [Release checklist](../RELEASE_CHECKLIST.md): stable-candidate acceptance and
  publication checks.
- [Chrome Web Store scope](../CHROMEWEBSTORE.md): current distribution decision and
  store-specific requirements.
- [Changelog](../CHANGELOG.md): published release history.

The repository root is loaded directly as an unpacked Manifest V3 extension. There
is no production build output or separately deployed documentation site.
